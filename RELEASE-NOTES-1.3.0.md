Mod Manager 1.3.0: installs each mod where its loader looks, and tells you when a mod can't work in this game and why. The loader is unchanged from 1.2.0.

- **Sprocket-Mod-Manager-1.3.0.zip:** extract as ModManager beside Sprocket.exe. Requires Windows and Python 3.11+ with Tkinter. Existing users replace `modman.pyw` and `loader_setup.py`, add the new `mod_compat.py`, and keep their configuration and data. **Install mod loader** still installs the 1.2.0 loader.
- Manual setup is unchanged: use **Sprocket-Mod-Loader-1.2.0.zip** from the 1.2.0 release.
- Loose DLLs install where their loader looks. The manager reads each DLL's .NET metadata without running it: MelonLoader mods go to `MLLoader\Mods`, plugins to `MLLoader\Plugins`, libraries to `MLLoader\UserLibs`, BepInEx plugins to `BepInEx\plugins`. Full folder layouts are kept. Mono or old-IL2CPP BepInEx builds, and Melon mods without MLLoader installed, are refused with an explanation.
- Disabling a mod restores the game's original files even when the manager and the game are on different drives.
- Enabling a mod warns if it can't fully work in this game. The new **Mod report** button (or `python modman.pyw --report "<game>"`) lists, for every enabled mod: assemblies it needs that the game and loaders don't have; game or Unity code it calls that this build lacks, checked by name and number of arguments; libraries no installed mod uses; enabled mods whose files were deleted; and which mod each error in the last game session's log came from, plus text the game's font can't show.
- Tested on the test copy with 12 community MelonLoader mods, UnityExplorer 4.13.6 and XUnity.AutoTranslator 5.6.2 with a Chinese translation. All installed where their loader looks. The report named, before launching, the mods that can't fully work on Sprocket 0.2.55.5 / Unity 6000.3.21f1 (made for an older game or Unity version), and matched the errors recorded in play. Those mods need updates from their authors; the manager can't fix them.

The manager self-test, the nine loader-setup tests and the four new metadata-reader tests pass. The loader's 1.2.0 preview limitation still applies: a separate UnityPlayer crash was recorded during a later shutdown.
